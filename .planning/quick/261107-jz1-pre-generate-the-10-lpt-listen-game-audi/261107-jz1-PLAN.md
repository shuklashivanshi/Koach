<objective>
Pre-generate the 10 Learning Pattern Test "Listen & Recall" clips (forms A/B x lists 0-4) once with the existing Cloud TTS path (`synthesize` in packages/ai/src/tts.ts), store them as static mp3 assets under apps/api/assets/lpt-audio/, and serve them from GET /lpt/audio/:form/:list in apps/api/src/routes/v1/learner/lpt.ts instead of calling deps.ai.speak on every request. Live TTS stays as the fallback for any missing or stale clip.

Purpose: The 10 lists are fixed, so synthesising them per request wastes TTS spend (budget: < US$2 per active user per month) and adds latency to the LPT. Static clips make the listen game instant and free after one generation run.

Output: clip store + generator module, route change with fallback, user-runnable generation script (with --dry-run/--force), tests that need no credentials, Dockerfile + asset directory so the image ships the clips.
</objective>
