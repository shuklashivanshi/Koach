  <action>
- `infra/env/dev.env` (committed, no secrets):
  - `PROJECT_ID=koach-dev-<suffix>` (suffix generated once by bootstrap and written back)
  - `REGION=asia-south1`, `AR_REPO=koach`, `SQL_INSTANCE=koach-pg`, `SQL_TIER=db-f1-micro`, `DB_NAME=koach`, `DB_USER=koach_app`
  - `BUCKET=${PROJECT_ID}-user-data`, `BUDGET_INR=2000`, `BILLING_ACCOUNT=` (filled by the user), `GOOGLE_WEB_CLIENT_ID=` (filled after Firebase setup)
- `lib.sh`: helpers `exists_or_create` (describe → create), `log`, `die`. `set -euo pipefail` everywhere.
- `bootstrap.sh <env>` performs, each step guarded by a describe check:
  1. Create the project and link billing.
  2. Enable APIs: run, sqladmin, artifactregistry, cloudbuild, secretmanager, aiplatform, texttospeech, speech, storage, iam, cloudscheduler, pubsub, billingbudgets, firebase, identitytoolkit.
  3. Create the Docker Artifact Registry repo.
  4. Create service accounts with roles:
     - `koach-api`: cloudsql.client, aiplatform.user, secretmanager.secretAccessor, storage.objectAdmin on the bucket only, firebaseauth.admin, and iam.serviceAccountTokenCreator on itself (needed to sign Firebase custom tokens on Cloud Run)
     - `koach-jobs`: cloudsql.client, aiplatform.user, secretmanager.secretAccessor
     - Cloud Build SA: run.admin, iam.serviceAccountUser on both SAs, artifactregistry.writer, secretAccessor
  5. Create the Cloud SQL Postgres 16 instance (Enterprise, `db-f1-micro`, `asia-south1`, backups on), then the database and user. Generate the password with `openssl rand`, piping it **directly** into Secret Manager.
  6. Create secrets:
     - `DATABASE_URL` (`postgresql://koach_app:<pw>@/koach?host=/cloudsql/PROJECT:REGION:koach-pg`)
     - `FIREBASE_PROJECT_ID`
     - `RESEND_API_KEY` (read with `read -s` from the prompt, never echoed)
  7. Create the GCS bucket (uniform access, region asia-south1).
  8. Create the budget (₹2,000, thresholds 0.5 / 0.9 / 1.0).
  9. Run `firebase projects:addfirebase`, create the Android app with package `com.koach.app`, and write `apps/mobile/google-services.json` (gitignored).
- `verify.sh <env>`: read-only describe of each resource. Print a ✓/✗ table and exit 1 on any ✗.
- README: prerequisites, the user steps, and how to run for prod later.
- Pass ShellCheck.
