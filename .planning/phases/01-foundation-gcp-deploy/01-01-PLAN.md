- Workspace globs `apps/*` and `packages/*`. Root scripts: `typecheck` (`pnpm -r typecheck`), `lint` (`eslint .`), `test` (`vitest run`), `format` (`prettier --check .`).
- `tsconfig.base.json`: strict true, noUncheckedIndexedAccess true, module/moduleResolution NodeNext, target ES2023.
- ESLint 9 flat config with typescript-eslint recommended-type-checked, plus a `no-restricted-imports` rule banning `@google/genai` outside `packages/ai`. Prettier with defaults.
- `.gitignore`: node_modules, dist, .env*, `apps/mobile/google-services.json`, `*.keystore`, `.expo`.
- **packages/shared**: zod schemas in `src/api.ts`:
  - `MeSchema` {uid, email nullable, createdAt ISO}
  - `EmailStartRequest` {email}
  - `EmailVerifyRequest` {email, code: 6 digits}
  - `EmailVerifyResponse` {customToken}
  - `ExportBundleSchema` {user, emailCodes: [], aiCalls: [], storageObjects: string[]}
  - `AiPingResponse` {text, audioBase64, model, costUsd}

  Export the inferred types.
- **packages/db**: Drizzle (pg-core) with one file per table under `src/schema/`:
  - `users` (uid text pk, email text null, created_at timestamptz default now)
  - `email_codes` (id uuid pk, email text, code_hash text, salt text, expires_at, attempts int default 0, created_at, ip text) with an index on (email, created_at)
  - `ai_calls` (id uuid, uid text null, feature, model, input_tokens int, output_tokens int, chars int, est_cost_usd numeric(10,6), latency_ms int, created_at)

  Make `ai_calls.uid` FK → users(uid) `on delete cascade`; `email_codes` is keyed by email and is deleted explicitly by the delete flow.
- The first migration starts with `CREATE EXTENSION IF NOT EXISTS vector;`. Generate migrations with drizzle-kit into `packages/db/migrations/`.
- `src/migrate.ts` exports `runMigrations(db)`; `src/testing.ts` creates a PGlite instance with the vector extension and runs the migrations.
- `users.test.ts`: migrate PGlite, insert a user, read it back, and validate it with `MeSchema`.
