  <action>
1. After the user's `eas login`, run `eas init` (writes projectId to app config via the CLI).
2. Set the development profile env: `EXPO_PUBLIC_API_URL` = the koach-api URL, `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` from dev.env.
3. Upload `google-services.json` as an EAS **file** environment variable named `GOOGLE_SERVICES_JSON` (never committed).
4. Run `eas build --profile development --platform android --non-interactive`.
5. `register-sha1.sh`: read the keystore SHA-1 from `eas credentials --platform android` JSON output, then `firebase apps:android:sha:create <appId> <sha1>` (idempotent).
6. Print the build's install URL / QR.
  </action>
