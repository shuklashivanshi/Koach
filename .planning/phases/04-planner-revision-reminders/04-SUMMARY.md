# Phase 4 Summary: Planner, revision, reminders

## Built
- **`packages/planner`** (pure functions, 7 tests):
  - FSRS via ts-fsrs (retention 0.9, no fuzz), retrievability, and the ≥3-touches forecast.
  - EWMA mastery, decayed by retrievability for the heatmap.
  - Phases: Foundation until 31 Jan, Prelims-intensive after, with the ratio table.
  - `buildDay` reserves revise, CA and practice time, then fills Learn greedily by priority × (1 − mastery) ÷ minutes, with prerequisites first and at most 2 subjects a day. Mains-only topics are dropped in the Prelims phase.
  - Every Learn task has a book + chapter and a goal line. Display order follows the spec, with CA last until the quiz exists.
  - `replan` (N minutes, due reviews kept, one task trimmed) and `rebalance` (moved tasks plus a note).
  - Priority = PYQ frequency + section weight, blended with a paper base weight so plans stay sensible before tags exist (CSAT lowest).
- **Database (0005):** `node_mastery`, `srs_cards`, `plan_tasks`, `plan_notes`, `mistakes`, `recall_items` (shared cache), `notification_prefs`, `push_subscriptions`, `notification_log`.
- **API routes:**
  - plan: `/v1/plan/today` (generated once a day; missed tasks are carried with a note), `/v1/plan/replan`, task done
  - study: `/v1/learn/:node` (GET/POST), `/v1/practice`, `/v1/reviews/due` and grading, `/v1/mistakes` (+ cause, 30-day traps), `/v1/mastery`
  - reminders: `/v1/notifications`, `/v1/push/*`, and `/internal/reminders`, which is guarded by the scheduler secret
- **Learn sessions:**
  - 2–3 PYQs, then source and chapter, then the goal, then 3–5 recall items.
  - Recall items are generated by Gemini, then verified by a second pass; only verified items are kept, and they're cached per node.
  - Missed recalls become cards. Wrong MCQs become mistakes plus cards.
- **Reminders:**
  - Rules decide; four types with tone copy, checked at ≤30/≤60 characters and against the naming guard.
  - Never in work or quiet hours; at most once per type per day.
  - Web Push with VAPID keys from Secret Manager (local: a gitignored `dev-keys.json`).
  - Cloud Scheduler job `koach-reminders` runs every 15 minutes.
- **Web screens:**
  - Today: task list, current-task marker, "Why this?" on long-press, "Short on time?" replan, Begin
  - Learn, Revise (Again/Hard/Good/Easy), Practice, Mistakes, CA placeholder
  - Memory heatmap and Reminders, both linked from You
  - Service worker for pushes
